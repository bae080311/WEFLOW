## 1. 전체 목표

- WEFLOW 마케팅 웹사이트를 **전면 재구성(전체 UI/UX 재설계)** 한다. 일부 수정이 아니다.
- 핵심 메시지: **"문의로 이어지는 홈페이지를 만듭니다."** (단순 제작이 아닌 *문의 구조*까지 설계).
- 모든 CTA는 실제 경로 또는 외부 링크로 연결되어야 한다.
- 사용자가 예약/무료진단을 신청하면 **관리자 페이지에 떠야** 하고, 관리자는 **실시간 수정/삭제/상태변경/엑셀 다운로드**가 가능해야 한다.
- 모바일은 PC와 동일한 내용을 보여주며, 렉/글자/이미지 잘림이 없어야 한다.
- **디자인은 `design-system.md` 기준**(WEFLOW 브랜드 컬러 + 토스식 구조)을 따른다.

## 3. 페이지별 요구사항

### 3-1. 홈 `/`
1. **히어로**: 배너 부제 "랜딩&홈페이지 제작 · 광고 운영 · 검색 상단 노출 · 맞춤형 웹 솔루션"(작은 글씨) → 큰 2줄 제목(줄 안 끊기게) **"문의로 이어지는 홈페이지를 만듭니다"** → 작은 글씨 "홈페이지 제작부터 광고 연동·운영 관리까지 / 단순 제작이 아닌 문의 구조까지 설계합니다".
   - **버튼 3개**(파란색): `무료 진단 신청`→`/diagnosis`, `성공 사례 보기`→`/cases`, `WEFLOW 랜딩 페이지`→`/landing`.
   - **칩 3개**(작은 직사각형, 가로로 늘리지 말 것): `케어 플랜(제작·광고·운영)`, `빠른제작(3일~7일)`, `합리적 비용(가성비+퀄리티)`.
2. **WEFLOW 케어플랜 혜택**: 6칸 박스 — weflow 케어플랜 / 제작+운영+광고+관리 원터치 / 빠른 제작(3~7일, "로켓배송") / 합리적인 가성비 / 24시간 상담대기(빠른 상담·피드백) / 운영·광고 지원(사후관리).
3. **배송 흐름(4단계)**: 고객의뢰 → 접수 후 제작 → 3~7일 배송완료 → 광고 및 운영 사후관리.
4. **성공사례 섹션**: 왼쪽 박스(큰 글씨 "다양한 업종의 성공 사례를 확인하세요", 작은 글씨 "어디서도 볼 수 없는 업종별 전환 최적화 사례", `살펴보기→` 버튼 → **/diagnosis** ⚠확인필요) + 오른쪽 케이스 이미지 5개(PT/필라테스/보험설계/카센타 등) + `더보기→`→`/cases`.
5. **제작진행과정(4단계) + 6단계 제작 프로세스 — 양옆 나란히 배치**:
   - 4단계: 고객 상담 / 협의 후 제작 / 3~7일 완료 / 광고 및 운영 사후관리.
   - 6단계: 01 상담·진단 / 02 기획·설계 / 03 디자인 / 04 개발·제작 / 05 SEO 최적화 / 06 광고운영·사후관리.
6. **무료진단 받기 섹션**: 큰 글씨 "무료진단 받기" + 박스 안 체크 4개 `✓ 문의 구조 진단 ✓ 디자인 점검 ✓ 검색 노출 분석 ✓ 문의 개선 제안` + 버튼 → `/diagnosis`.
7. **후기 마퀴**: 다수 5점 후기(가로 자동 스크롤, 2줄 박스가 양옆으로 넘어감) + 우상단 `후기 더보기→` → **문의 모달 오픈**.

### 3-2. 서비스 `/services`
1. **제작진행과정 6단계(설명 포함)**:
   - 01 상담·진단 — 업종 및 제작 방향 확인
   - 02 기획·설계 — 문의 구조 및 전략 설계
   - 03 디자인 — 브랜드 맞춤 화면 구성
   - 04 개발·테스트 — 기능구현 최적화, 검수 및 수정 진행
   - 05 SEO 상단등록 — 네이버·구글·사이트맵 등록
   - 06 광고운영·사후관리 — 인스타·블로그·네이버 키워드 광고 운영관리
2. **광고 운영·사후관리 시스템**: 블로그 업로드 / 인스타 업로드 / 스레드 업로드 / 네이버 키워드 업로드 / 당근플레이스 키워드 업로드 / 네이버 서치어드바이저 상단등록 / 구글 콘솔 상단등록 / 사이트맵 등록.

### 3-3. 제작플랜&가격안내 `/pricing`
- "**필수 선택형 (3중 택1)**" 안내, **세로 카드형 1열**, 모든 카드에 `✓` 기능 리스트.
- 가격은 **정가(취소선) 위 → 할인가 아래** 2줄 강조("파격세일" 느낌).
- **총 8개 카드** (아래 §5 데이터 표 참조). MASTER(제작) · WEFLOW CARE(케어)는 **색상 다르게 + 왕관(crown) 강조**.
- 하단 공통 안내: 각 가격 **VAT 포함**. 도메인은 고객 명의 등록·비용 별도(WEFLOW 등록/연결 세팅 무료). 광고비는 고객 계정에서 직접 결제(WEFLOW는 운영·세팅만). 유지보수는 텍스트·이미지·링크 등 **경미한 수정 기준**, 페이지 추가·기능 개발은 별도 비용.

### 3-4. 성공사례 `/cases`
- **1열 카드**(아래로 쭉, center 정렬, 양옆 여백). 카드 상단 이미지 / 하단 상호명 + `자세히 보기`.
- 카드/`자세히 보기` 클릭 → **내부 상세 `/cases/[slug]`** (외부 데모 링크로 보내지 말 것 ⚠).
- 맨 아래 `더보기→` → **문의 모달 오픈**.
- 업종 목록(§6) 기준 카드 생성. 케이스 이미지는 참고 레포 `public/cases_*.jpg`에 존재(P0에서 이관).

### 3-5. 예약 `/reservation`
- **세로형 달력** 날짜 선택(과거 날짜 선택 불가).
- **시간 그리드**: 09:00 ~ 18:30, **30분 간격 = 총 20개**, **가로 5 × 세로 4줄**. 선택 날짜가 오늘이면 **현재 시각 이전 슬롯은 비활성**(예: 지금 13시면 13시 이전 비활성).
- **원하시는 시간대(직접 입력)** 칸(그리드와 상호배타: 직접 입력 시 그리드 선택 해제).
- 필드: **이름 / 연락처** · **제작종류**(드롭다운: 랜딩페이지 제작 / 홈페이지 제작 / 랜딩&홈페이지 제작 / 기타(weflow 케어플랜)) · **업종 입력** · **추가요청사항** · ☑ **개인정보 수집 및 상담 동의**(필수).
- 제출 → **관리자 예약 관리**에 표시.

### 3-6. 무료진단받기 `/diagnosis` (신규)
- 제목 "무료진단 받기 / 무료진단 후 견적받기".
- 필드: **이름 / 연락처** · **제작종류**(예약과 동일 4옵션) · **업종 입력** · **추가요청사항** · ☑ **개인정보 수집 및 상담 동의**(필수).
- 제출 → **관리자 문의 관리**에 표시(`source: diagnosis`).
- (선택) 무료진단 체크리스트(✓4) 재사용 가능.

### 3-7. 랜딩 `/landing`
- 큰 문구 "문의로 이어지는 홈페이지를 만듭니다" / 작은 문구 "기획부터 제작, 광고 연동, 운영 관리까지 WEFLOW가 함께합니다."
- CTA: `무료진단 후 견적받기`(→ 문의 모달/sticky 폼), `실제 제작 성공 보기`(→ `/cases` 권장 ⚠메뉴얼은 "문의").
- **우측 고정(sticky) 문의 폼**(스크롤 시 같이 내려옴): 이름/연락처/제작종류/업종/추가요청사항/☑동의 + 버튼 → **관리자 문의 관리**(`source: landing`). 모바일에서는 본문 아래로 흐름 전환.
- 가치 섹션: WEFLOW CARE PLAN / 빠른 제작 진행(랜딩 3~4일, 홈페이지 약 1주) / 합리적인 비용 / 24시간 상담 가능 / 제작 후 운영 관리 / 광고 연동 지원(인스타·스레드·블로그·카카오톡·당근) / 문의 증가 구조 설계(업종별 흐름 분석·상담 버튼 위치 최적화·모바일 동선).
- **재사용("퍼오기")**: 가격 카드 8개 전부 / 서비스의 제작진행과정 / 무료진단 체크리스트(✓4) + 버튼(→`/diagnosis`) / 후기 전부.
- Footer 동일.

### 3-8. 관리자 `/admin` (신규, 로그인 게이트)
- **로그인** 후 진입(참고 예시 계정 `badeagle85@gmail.com / 1111` → 시드/ENV로 관리, 하드코딩·커밋 금지).
- 상단: **전체 엑셀 다운로드**(예약+문의를 한 파일로) · **새로고침** · **로그아웃**.
- **상태 필터 탭**: 대기 / 진행중 / 완료 / **전체** — 실시간 반영. (`전체`는 필터일 뿐 상태값 아님. 신규 레코드 기본 상태 = **대기**.)
- **예약 관리 테이블**: 컬럼 `상태 · 이름 · 연락처 · 접수일 · 희망 일정 · 관리`. 관리 = `완료`/`진행중`/`삭제` 버튼(클릭 시 **실시간 반영**). 행 우측 **아래 화살표** → 상세(제작종류·업종·추가요청사항). **예약 엑셀** 다운로드.
- **문의 관리 테이블**: 컬럼 `상태 · 이름 · 연락처 · 접수일 · 관리`. 관리 = `완료`/`진행중`/`삭제`. **아래 화살표** → 상세(제작종류·업종·추가요청사항). **문의 엑셀** 다운로드.
- (관리자에서 CASE 페이지 수정 언급 → 콘텐츠 관리 범위는 구현 단계에서 확정.)

## 9. 폼 데이터 모델 (저장/엑셀 공통)

```ts
type ProjectType = "랜딩페이지 제작" | "홈페이지 제작" | "랜딩&홈페이지 제작" | "기타(weflow 케어플랜)";
type Status = "대기" | "진행중" | "완료";        // 기본값 "대기"; "전체"는 필터
type InquirySource = "diagnosis" | "landing" | "review_modal" | "cases";

interface Reservation {       // → 관리자 예약 관리
  id: string; status: Status; name: string; phone: string;
  createdAt: string;          // 접수일(ISO)
  desiredDate: string;        // 희망일
  desiredTime: string;        // 희망시간(20슬롯 중 하나 또는 직접입력)
  isManualTime: boolean;
  projectType: ProjectType; industry: string; note?: string;
  agreed: true;               // 개인정보 동의(필수)
  updatedAt?: string;
}

interface Inquiry {           // → 관리자 문의 관리 (diagnosis·landing·modal 공통)
  id: string; status: Status; name: string; phone: string;
  createdAt: string;
  projectType: ProjectType; industry: string; note?: string;
  source: InquirySource;
  agreed: true;
  updatedAt?: string;
}
```
- 필수: 이름·연락처·제작종류·업종·동의(true). 예약은 추가로 희망일+희망시간. 추가요청사항은 선택.
- 저장은 **Repository 인터페이스 + Supabase 어댑터**로 추상화(→ `coding-rules.md`, `implementation-plan.md`).
